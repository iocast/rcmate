Configuration

One TOML file. Every sync pair.

Define sync pairs, paths and filters in ~/.config/rcmate/config.toml. Options are stored per pair and written back by the Options popup.

    {% for m in config.extra.modes %}

Full configuration reference →
config.toml 
[general]
log_path = "~/.local/state/rcmate/logs"
log_level = "info"

[rclone]
bin = "rclone"

[[sync_pairs]]
name = "Documents Sync"
type = "bisync"
source = "/local/documents"
destination = "remote:documents"

[sync_pairs.options]
dry_run = false
resync_mode = "none"
