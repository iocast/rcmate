## Main view

| Key | Action |
|-----|--------|
| <kbd>↑</kbd> / <kbd>↓</kbd> | Move selection up/down |
| <kbd>Space</kbd> | Toggle selection for sync |
| <kbd>a</kbd> | Toggle selection for all pairs |
| <kbd>Ctrl</kbd>+<kbd>s</kbd> | Start synchronization for selected pairs |
| <kbd>Ctrl</kbd>+<kbd>a</kbd> | Add a new sync pair |
| <kbd>e</kbd> | Edit the highlighted sync pair |
| <kbd>o</kbd> | Options for the highlighted sync pair |
| <kbd>p</kbd> | Per-file progress for the highlighted pair |
| <kbd>Alt</kbd>+<kbd>e</kbd> | Show the error of the highlighted pair |
| <kbd>Shift</kbd>+<kbd>Alt</kbd>+<kbd>I</kbd> | Open About/Info dialog |
| <kbd>q</kbd> / <kbd>Ctrl</kbd>+<kbd>C</kbd> | Quit application |

## Add / edit form

Both <kbd>Ctrl</kbd>+<kbd>a</kbd> and <kbd>e</kbd> open the same form.

| Key | Action |
|-----|--------|
| <kbd>Tab</kbd> / <kbd>Shift</kbd>+<kbd>Tab</kbd> | Move between fields |
| <kbd>Enter</kbd> | Save the pair back to the config file |
| <kbd>Esc</kbd> | Cancel |
